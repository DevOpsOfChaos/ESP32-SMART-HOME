# Fabrication

This folder contains production-oriented outputs for the hardware designs.

Do not edit these files as if they were source code. Treat them as release artifacts derived from the board designs.

## Contents

- `gerbers/` - PCB manufacturing data
- `kicad/` - board project files and exports
- `schematics/` - schematic PDFs and handoff files
- `bom/` - bill of materials CSV exports

## Purpose

These files exist so someone can manufacture or review the boards without digging through the entire design history.
